## 主題簡述

建立全新基礎 Pack `cuboid_device`（無上游 Pack 依賴，僅依賴 `@/API`）。規範下游設備為 $N$ 維超長方體（Cuboid），以維度長度向量 `[delta_x, delta_y, delta_z, ...]` 定義跨度，並提供 Adapter 將長方體跨度轉換為核心引擎的 2× 網格 `shape` 單元格列表。

**本計畫的約束**

- 嚴格遵循 Allman 大括號風格、全小寫 snake_case 命名與結尾分號 `;`。
- 無上游依賴，僅依賴 `@/API`。
- 拒絕隱性補齊（No Implicit Zero-Padding），支援任意維度長方體。
- 透過 `cuboid_device` 統一物件導出，並實作 `init_pack()`。

## 規劃描述

1. **建立 `cuboid_device` 型別與介面 (`types.ts`)**：
   - 定義 `cuboid_dimensions` / `cuboid_device` 能力介面契約。
2. **實作長方體至核心 Shape 的 Adapter (`adapter.ts`)**：
   - 實作 `cuboid_to_shape(dimensions: vector): vector[]`，以遞迴/泛型方式生成符合 $N$ 維 2× 網格單元格座標列表。
3. **實作 `base_cuboid_device` 基礎類別 (`base_device.ts`)**：
   - 繼承 `device`，封裝 `dimensions` 並自動由 Adapter 計算 `shape`。
4. **Pack 統一導出與初始化 (`index.ts`)**：
   - 統一導出物件 `export const cuboid_device = { ... }` 與生命週期函式 `init_pack()`。
5. **編譯驗證**：
   - 執行 `npm run build` 確認 0 錯誤。
