# 開發 TODO List 202608122157：Camera N 維切面方程式指令 (camera --"<eq>")

## 1. 背景與決策原委

引擎支援 N 維空間繪製，在 2D 畫布上呈現畫面時，必須顯示其中 2 個維度（`dim_h` 水平軸、`dim_v` 垂直軸），並固定其餘 $N-2$ 個維度（`slices` 切片深度）。

為了讓使用者能直覺地在 CMD 系統中調整檢視切面，設計方程式語法：`camera --"<axis>=<depth>, ..."`。

### 語法規範
- **語法格式**：`camera --"<軸1>=<深度1>, <軸2>=<深度2>"`
- **軸名稱對應**：`x` (索引 0)、`y` (索引 1)、`z` (索引 2)、`w` (索引 3)、`d<n>` (索引 n)。
- **3D 範例（固定 1 軸）**：
  - `camera --"z=0"` → 固定 $Z=0$，顯示 $X$-$Y$ 平面
  - `camera --"x=1"` → 固定 $X=1$，顯示 $Y$-$Z$ 平面
  - `camera --"y=2"` → 固定 $Y=2$，顯示 $X$-$Z$ 平面
- **4D 範例（固定 2 軸）**：
  - `camera --"z=0, w=1"` → 固定 $Z=0, W=1$，顯示 $X$-$Y$ 平面
- **查詢目前狀態**：`camera`（不帶參數，顯示目前 2D 平面與切片資訊）
