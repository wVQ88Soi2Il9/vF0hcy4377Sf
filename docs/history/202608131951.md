# 開發歷史紀錄 202608131951：[0, 2) 半開區間邊界與切面 Ghost Layer 渲染邏輯調整

## 1. 背景與需求調整 (Background & Requirement Adjustment)

- **使用者需求**：當切片選擇 $Y=2$ 時，能半透明顯示佔據區間 $[0, 2)$（細胞座標 $Y \in \{0, 1\}$）的物件。
- **邊界邏輯解析**：
  - 一個佔據半開區間 $[0, 2)$ 的物件，其最上層細胞座標為 $Y=1$。
  - 當切片切在 $Y=2$ 時，切片平面與該物件的最頂端邊界相鄰（距離 $dist = 2 - 1 = 1$）。
  - 因此，當 $S_Y = 2$ 時，物件屬於鄰近切面層 ($\Delta d = 1$)，應該以半透明模式 (`globalAlpha = 0.25`) 繪製整個物件的 2D 投影形狀。
