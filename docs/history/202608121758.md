# 開發 TODO List 202608121758：basic_ui 重構與 Canvas 移交

## 1. 背景與目標

原架構中，`packs/basic_renderer` 直接負責建立 `<canvas>` 並掛載至全域 `#app` DOM 節點。  
為了實現模組化與多元 UI 架構，現將 UI 佈局與元件管理交由新 Pack `packs/basic_ui` 統一維護。

**主要目標**：
- `packs/basic_renderer` 僅負責 Canvas 的建立與繪製邏輯，不再直接掛載至 DOM (`#app`)。
- Canvas 主顯示區域將由 `basic_renderer` 導出/傳遞至 `basic_ui`。
- `packs/basic_ui` 負責初始化頂層 UI 結構（Vue / DOM 容器），並將 `basic_renderer` 提供的 Canvas 嵌入指定的主視圖區域 (Viewport)。

## 3. 架構預期程式碼示意

```typescript
let renderer_canvas: HTMLCanvasElement | null = null;

export function get_renderer_canvas(): HTMLCanvasElement | null
{
    return renderer_canvas;
}

export function init_pack(): void
{
    // 建立 canvas 但不直接 append 到 #app
    renderer_canvas = document.createElement('canvas');
    renderer_canvas.id = 'renderer_canvas';
    // 初始化繪製 logic...
}
```

### `packs/basic_ui/index.ts` 接收與掛載示意

```typescript
import { get_renderer_canvas } from '@/packs/basic_renderer';

export function init_pack(): void
{
    const host = document.getElementById('app') ?? document.body;
    
    // 建立 UI 容器...
    const viewport = document.createElement('div');
    viewport.id = 'canvas_viewport';
    host.appendChild(viewport);

    // 取得 renderer canvas 並放入 UI 容器
    const canvas = get_renderer_canvas();
    if (canvas)
    {
        viewport.appendChild(canvas);
    }
}
```
