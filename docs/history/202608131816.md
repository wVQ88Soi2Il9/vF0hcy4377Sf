# 開發歷史紀錄 202608131816：切面視覺邊界討論與 Ghost Layer (半透明鄰近切面層) 繪製機制實作

## 1. 背景與討論 (Background & Design Discussion)

在 N 維/3D 切面渲染視圖中，討論了座標邊界與可見性判斷：
- **問題**：對於 `pos=(0,0,0)`、尺寸為 `2x2x2` 的物件，在切片 $X=2$ 時是否可見？
- **分析**：
  - 在半開區間離散網格模型 $[a, b)$ 及 2× Grid 系統下，$pos=(0,0,0)$ 覆蓋範圍為 $[-1, 1]$，$X=2$ 屬於下一個格子中心 $(2,0,0)$，不可見是符合離散幾何邏輯的。
  - 然而，切片變換時物件若直接消失，缺乏視覺連續性。
- **決策**：引進 **Ghost Layer (半透明鄰近切面層)** 機制，在切面距離 $\Delta d = 1$ 的鄰近切面上以低透明度 (`globalAlpha = 0.25`) 繪製物件，解決空間視覺斷層問題。
