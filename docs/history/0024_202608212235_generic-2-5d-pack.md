## 主題簡述

針對 2.5D 場景（$\mathbb{Z} \times \mathbb{Z} \times \{0, 1, \dots, n\}$）開發通用 Pack（`layered_2d`）與基礎設施，包含 2.5D 主平面二面體群 $D_4$（4 向旋轉與鏡射翻轉）幾何變換、分層空間檢查與連接圖拓撲，以及全新優化的雙 Pass（Two-Pass）分層渲染器。

**本計畫的約束**

- 嚴格遵循 Allman 大括號風格、全小寫 snake_case 命名與結尾分號 `;`。
- 遵循三層單向架構，Pack 僅透過 `@/API` 與 Core 互動。
- 拒絕隱性補齊，向量長度嚴格為 3（`[x, y, z]`）。
- Pack 對外暴露之介面採用物件導出。

## 規劃描述

1. **2.5D D4 幾何變換系統（Rotate & Flip）**：設計並實作適用於 2.5D 水平主平面的 $D_4$ 群（4 向正交旋轉與鏡射翻轉）幾何變換輔助與裝置變換介面。
2. **2.5D 渲染器（Better Renderer）**：實作由底向高（Z 升序）分層渲染管線，並進一步研發高表現力視覺效果。
3. **完善 layered_2d 通用 Pack**：建立 `src/packs/layered_2d` 的專屬型別、引用 `vanilla` 空間檢查與拓撲圖，並由 `base_layered_device` 提供抽象繪圖契約。
4. **優化 UI Bar**：進行 UI Bar 介面與體驗優化（抽象目標，須由使用者明確指示 finish 始可結案）。

## 觀察與推論

### O1 · 2026-08-21 22:35:00+08:00 — 2.5D 場景之旋轉與分層渲染特性
在 2.5D 場景中，旋轉嚴格局限於 $xy$ 主平面之 4 個正交朝向（North/East/South/West），垂直 $z$ 軸則為離散有限層級。此特性使得旋轉計算大幅簡化，同時渲染器可擺脫高維切面公式，專注於多層疊加 (Layer Stacking)、透明度深度差與直矩的層級導航體驗。

### O2 · 2026-08-21 23:05:00+08:00 — 引入 D4 二面體群幾何對稱性
平面網格幾何變換的完整對稱群為 8 階二面體群 $D_4$（包含 4 個旋轉 $r \in \{0, 1, 2, 3\}$ 與 1 個鏡射翻轉 $s \in \{0, 1\}$，滿足 $srs = r^{-1}$）。引入 $D_4$ 能完整覆蓋非對稱建築與管道的旋轉與鏡向鏡射需求。

### O3 · 2026-08-21 23:41:00+08:00 — 2.5D 分層視覺表現
目前基礎的半透明疊加已能表達層級關係，但視覺表現仍待優化。

### O4 · 2026-08-21 23:44:00+08:00 — UI Bar 優化
UI Bar 待進一步優化。

### O5 · 2026-08-22 00:00:00+08:00 — UI Bar 互動操作遷移
將 CMD 高頻操作（刪除、偶數座標移動、食譜選擇）整合至 Info Bar 互動面板。針對 Z 層級切換器與 2.5D D4 旋轉翻轉，因常態 2D 場景通常無 Z 軸/D4 變換需求，暫存為待辦；裝置建造工具列（Palette / Creator）標記為待決斷。
