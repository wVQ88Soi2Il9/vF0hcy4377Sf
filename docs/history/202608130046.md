# 開發歷史紀錄 202608130046：修復 Camera 指令 Flag 解析與拆分獨立 cmd_tool Pack

## 1. 背景與問題

在使用 CMD 系統調整渲染視角（如 `camera --"d3=0"` 或 `camera --"z=0"`）時，出現無法順利調整切面視角與切片深度的問題。

經排查發現：
1. `clean_flag_arg()` 函式誤將包含等號 `=` 的 Flag 參數前綴（如 `d3=` / `z=`）切除，導致 `camera` 方程式解析器無法識別正確的軸名稱而丟出格式錯誤。
2. 文字與 Flag 解析邏輯原本內嵌在 `cmd_executor.ts` 中，為了模組化與權責分離，將其獨立抽離為新的 Pack `cmd_tool`。

---
