# 開發 TODO List 202608122145：basic_ui 內部模組拆分與 CMD 指令系統

## 1. 背景與決策原委

`basic_ui` 為開發過渡期的暫時性 Pack，以開發方便與快速驗證為主要考量。  
為了維持靈活度與清晰的程式碼架構，同時不額外增加 Pack 數量或修改 `packs/loader.ts`，決定將 UI 與指令邏輯在 `packs/basic_ui/` 內部進行檔案級別的關注點分離（Separation of Concerns）：

```
src/packs/basic_ui/
├── index.ts          # basic_ui 啟動入口與事件訂閱
├── layout.ts         # 主 UI 佈局 DOM 建構 (#ui_root, #canvas_viewport)
├── info_bar.ts       # 右側 Info Bar 面板組件與狀態更新介面
├── cmd_bar.ts        # 下方 Command Bar 面板組件與 DOM 事件
└── cmd_executor.ts   # 獨立指令解析與執行器 (對接引擎 @/API)
```

- **`info_bar.ts`**：專注於右側地圖與裝置狀態卡片的呈現。
- **`cmd_bar.ts`**：專注於下方命令列輸入框與按鍵觸發事件。
- **`cmd_executor.ts`**：專注於指令字串解析（如 `add`、`delete`、`move`、`rotate`、`help`）並對接 `@/API` 呼叫，完全無 DOM 依賴。
