## 主題簡述

實作「拖曳物品」互動功能，包含畫布內裝置的點選拖曳移動（Drag to Move）以及從側邊面板拖曳建立新裝置至畫布視口（Drag to Create）。

**本計畫的約束**

- 嚴格遵循 Allman 大括號風格、全小寫 snake_case 命名與結尾分號 `;`。
- Packs 禁止直接 import `@/core`，只能透過 `@/API` 存取。
- CLI 與互動建立/移動必須嚴格保證各維度座標為偶數 integer（Even Coordinates）。
- 移動與建立操作統一透過 `@/API` 的 `move_device_command` 與 `create_device_command` 經由歷史管理系統執行，以支援 Undo/Redo。
- 拒絕隱性補齊。
- 更新後執行 `python docs/history/update-head.py`。

## 規劃描述

1. **視口座標逆變換與裝置拾取判定 (`basic_renderer`)**：
   - 實作 `screen_to_grid` 函式，將螢幕像素座標轉換為世界網格浮點與最近偶數網格座標。
   - 支援依據當前相機切片平面（`camera.plane`）判定點擊或落點是否命中特定裝置。
2. **畫布內裝置拖曳移動互動 (`basic_renderer` / `shirones_ui`)**：
   - 區分畫布平移（Camera Pan）與裝置選取/拖曳（Device Drag）。
   - 拖曳過程支援輪廓/幽靈預覽吸附至偶數網格。
   - 釋放時透過 `execute_command(move_device_command(...))` 執行移動。
3. **從 UI 面板拖曳建立裝置至畫布 (`shirones_ui`)**：
   - 支援從 Device Creator 或側邊工具拖曳物品進入 Viewport。
   - 放置時自動轉換落點網格並呼叫 `create_device_command` 建立新裝置。
4. **驗證與建構測試**：
   - 驗證拖曳移動與生成在 2D/3D 切片下之座標正確性、吸附精準度與 Undo/Redo 操作連動。
