# basic_renderer — 功能草稿

為 cleanroom design 而留:只列原實作提供的功能,不描述做法。原始碼見 git 歷史(刪除前最後一版:`4ad764d`)。

## 定位

把一份 2D 投影畫成畫面。不做投影,也不知道空間有幾維;投影由 `camera` 提供。

## 功能

1. **視口**:依投影大小產生一塊畫面,可選擇是否顯示背景格線。
2. **裝置繪製**:畫出投影中的每個裝置。
   - 裝置自己提供畫法時,使用裝置的畫法。
   - 否則使用預設畫法(功能 3)。
3. **預設裝置畫法**:
   - 畫出裝置的形狀。
   - 可選擇顯示標籤:裝置種類的簡稱,滑鼠停留時顯示完整名稱與編號。
   - 可選擇顯示埠:依輸入、輸出、雙向區分外觀,滑鼠停留時顯示埠編號與方向。
4. **縮放**:可指定一格的顯示大小。
