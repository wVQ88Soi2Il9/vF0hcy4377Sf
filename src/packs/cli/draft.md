# cli — 功能草稿

為 cleanroom design 而留:只列原實作提供的功能,不描述做法。原始碼見 git 歷史(刪除前最後一版:`1aa21ca`)。

## 定位

用一行文字呼叫各 pack 提供的指令。CLI 本身不內建業務指令。

## 功能

1. **輸入**:以空白分隔指令與參數;引號內的空白不分隔。
2. **參數轉型**:布林值、null、數字自動轉型,其他保留為文字。
3. **指令查找**:可寫成「pack:指令」指定來源,也可只寫指令名稱。
4. **說明**:列出所有指令,或查詢單一指令;顯示各指令提供的描述。
5. **Console 使用**:在瀏覽器 DevTools Console 直接輸入指令,結果與錯誤印在 Console。
6. **解析輔助**:供指令實作驗證座標與整數參數,格式錯誤時報錯。
