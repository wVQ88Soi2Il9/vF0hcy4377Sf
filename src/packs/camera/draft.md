# camera — 功能草稿

為 cleanroom design 而留:只列原實作提供的功能,不描述做法。原始碼見 git 歷史(刪除前最後一版:`4ad764d`)。

## 定位

從 N 維空間取出一個 2D 視圖,交給 `basic_renderer` 繪製。

## 功能

1. **選軸**:指定哪兩個軸作為畫面的水平、垂直方向。
2. **切片**:其餘的軸各指定一個位置,只看該位置上的內容。
3. **可見規則「接觸即傳」**:裝置只要有任何部分碰到切片,就整個顯示,不裁切。
4. **投影結果**:視圖大小、可見裝置,以及選軸、切片等附帶資訊。
5. **繪製**:投影後直接畫出。
