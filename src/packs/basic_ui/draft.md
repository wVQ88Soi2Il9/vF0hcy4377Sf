# basic_ui — 功能草稿

為 cleanroom design 而留:只列原實作提供的功能,不描述做法。原始碼見 git 歷史(刪除前最後一版:`7d4889b`)。

## 定位

UI 的基礎零件,不包含任何具體畫面。其他 pack 用它組出介面,或把自己的內容掛進介面。

## 功能

1. **UI 根容器**:全頁唯一的 UI 掛載點,由使用者指定放在哪裡。
2. **浮動面板**:有標題與內容區的面板。
   - 可收合。
   - 可從指定的邊拖曳調整大小,大小有上下限。
3. **分割線**:放在兩個相鄰區塊之間,拖曳時一邊變大、另一邊變小,兩邊各有最小值。
4. **擴充點**:其他 pack 可註冊、取消註冊下列內容:
   - 裝置檢視器:依裝置決定是否顯示的資訊區塊。
   - 裝置動作:對裝置執行的操作,可標示為危險操作。
   - 面板區段:依優先序排列的區塊。
   - 裝置建立選項:建立裝置時的額外設定,依裝置種類決定是否出現。
5. **裝置資訊轉接**:讓「顯示 / 清除某個裝置的資訊」的請求,轉給目前負責顯示的元件。
6. **外觀**:一致的深色主題,涵蓋面板、拖曳把手、分割線與捲軸。
